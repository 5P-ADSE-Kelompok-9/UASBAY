# Board Game Buddy - Spring AI Chapter 1

Project bundle based on Chapter 1 of the uploaded *Spring AI in Action* PDF.

## Main project settings

- Gradle Groovy DSL
- Spring Boot 3.5.5
- Java toolchain 24
- Spring AI 1.0.1
- Spring Web + Spring AI OpenAI starter
- WireMock Spring Boot test dependency

The `BoardGameBuddyApplication.java` file is included as the standard Spring Boot entry point generated by Spring Initializr; Chapter 1 focuses its printed source examples on the service, controller, and test classes. The `application.properties` file reads the key from the environment variable.

ZIP ini sudah menyertakan launcher `gradlew.bat` (Windows) dan `gradlew` (macOS/Linux), serta konfigurasi versi Gradle 8.14.8. Launcher akan mengunduh distribusi Gradle resmi pada pemakaian pertama dan memverifikasi SHA-256-nya. Tidak perlu memasang Gradle secara global, tetapi koneksi internet diperlukan saat unduhan pertama.

## Set your OpenAI API key

Do not paste a real API key into source control. Set an environment variable before running the app.

macOS / Linux:

```bash
export SPRING_AI_OPENAI_API_KEY="sk-your-real-api-key"
```

Windows Command Prompt:

```bat
set SPRING_AI_OPENAI_API_KEY=sk-your-real-api-key
```

## Run

```bash
./gradlew bootRun
```

On Windows:

```bat
.\gradlew.bat bootRun
```

## Try the REST endpoint

```bash
curl localhost:8080/ask \
  -H "Content-Type: application/json" \
  -d '{"question":"Why is the sky blue?"}'
```

Or with HTTPie:

```bash
http :8080/ask question="Why is the sky blue?" -b
```

## Run the WireMock test

```bash
./gradlew test
```

On Windows PowerShell, run:

```powershell
.\gradlew.bat test
```

The test uses `src/test/resources/test-openai-response.json` to return a fixed `Paris` response from a mocked OpenAI endpoint. It does not need a real OpenAI API key.

## Optional configurations also shown in Chapter 1

These are alternatives; do not add all provider starters together unless you intentionally want multiple providers.

### Choose another OpenAI model

Add this to `src/main/resources/application.properties`:

```properties
spring.ai.openai.chat.options.model=gpt-4.1-nano
```

List models (requires HTTPie and a configured key):

```bash
http -A bearer -a "$SPRING_AI_OPENAI_API_KEY" https://api.openai.com/v1/models
```

### Azure OpenAI alternative

Dependency:

```groovy
implementation 'org.springframework.ai:spring-ai-starter-model-azure-openai'
```

Properties (replace the placeholder with your own key, preferably via an environment variable instead of committing it):

```properties
spring.ai.azure.openai.api-key=${SPRING_AI_AZURE_OPENAI_API_KEY}
spring.ai.azure.openai.chat.options.deployment-name=gpt-4
```

Set the environment variable on macOS/Linux:

```bash
export SPRING_AI_AZURE_OPENAI_API_KEY="your-azure-api-key"
```

### Ollama alternative

Pull one of the models shown in Chapter 1:

```bash
ollama pull gemma:2b
ollama pull mistral:7b
```

Other commands from the chapter:

```bash
ollama list
http http://localhost:11434/api/tags -b
```

Dependency:

```groovy
implementation 'org.springframework.ai:spring-ai-starter-model-ollama'
```

Properties:

```properties
spring.ai.ollama.chat.model=gemma:2b
spring.ai.ollama.init.pull-model-strategy=when_missing
```

The `spring.ai.ollama.init.pull-model-strategy` setting can be `when_missing`, `always`, or `never` (the default described in Chapter 1).
